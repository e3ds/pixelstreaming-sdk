# E3DS Pixel Streaming SDK Demo Project

## Overview

This repository contains a **demo project** showcasing how to embed an Unreal Engine Pixel Streaming application into a web page using the **Eagle 3D Streaming (E3DS) Frontend SDK**.

It serves as a reference implementation to help developers understand how the SDK is used in a real integration scenario.

## What This Demo Shows

* How to integrate the E3DS Frontend SDK into a web project
* Secure connection and authentication handling via the SDK
* Web-based embedding of Unreal Pixel Streaming applications
* A production-aligned integration pattern

## Documentation
